# 📬 Sleep Boîtes aux Lettres

Je vous présente **Sleep Boîtes aux Lettres** ! 🎉  
Un simple addons qui ajoute un système de boîtes aux lettres pour déposer de l'argent, des armes et transmettre l'accès à un autre joueur.

## ⚡ Installation rapide

1. Téléchargez l'addon et glissez le dossier `sleep_bal` dans votre répertoire `addons/`.
2. Configurez l'addon dans `sleep_bal/lua/sleep_bal/sh_config.lua`.
3. Ajoutez les content dans votre collection : [Workshop Content](https://steamcommunity.com/sharedfiles/filedetails/?id=3585815875)
4. Redémarrez votre serveur.

Et voilà, votre système de **boîtes aux lettres** est prêt à l'emploi ! 🚀
